# Personal Homepage Template for Professors, Researchers, and Scientists

This project is a modern, responsive personal homepage template specifically designed for Professors, Researchers, and Scientists. It enables academics to showcase their research interests, publications, teaching, academic CV, and contact details in a clean, minimalist design.

## Features

- **Responsive Design** – Optimized for mobile, tablet, and desktop.
- **Fast** – Fast load time.
- **SEO Friendly** – Structured data and meta tags for better visibility.
